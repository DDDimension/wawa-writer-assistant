# 蛙蛙写作助手

为蛙蛙写作（wawawriter.com）定制的 Chrome 扩展：
一键加载投稿作品列表、获取作品收益、导出收益汇总 Excel。

## 功能

- **加载作品列表**：读取蛙蛙写作「投稿中心 → 作品管理」的全部投稿作品（自动翻页）。
- **一键获取收益**：读取每本作品的历史总收益、昨日收益、最新单日收益、收益趋势（最新日 vs 昨日）、在读人数。
- **导出Excel**：导出字段为 书名、笔名、状态、总字数、历史总收益、昨日收益、最新收益、收益趋势、在读人数、导出日期。
- 汇总卡片：作品数、历史总收益合计、昨日收益合计、最新收益合计。

## 使用方式

1. 在 Chrome 扩展管理页（`chrome://extensions`）打开右上角「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本目录 `D:\Program Files\蛙蛙写作助手_v1.0.0`。
3. 在浏览器中登录蛙蛙写作（wawawriter.com）。
4. 点击扩展图标打开功能页，依次点击「加载作品列表」→「一键获取收益」→「导出Excel」。

## 实现说明

- 收益口径与蛙蛙写作官方投稿页「作品收益」一致（历史总收益 / 单日收益 / 昨日对比 / 在读人数，均为税前金额）。
- 数据通过已登录的 wawawriter.com 标签页请求官方接口（Cookie 登录态），不会上传到任何第三方服务器。
- 接口清单（来自官方前端）：
  - `POST /wrhp-api/api/v1/submission/novel/my_list`（投稿作品列表，含每本作品 revenue）
  - `GET  /wrhp-api/api/v1/submission/novel/my_revenue`（账号收益汇总）
- 仅已签约（contracted）作品会返回收益数据；未签约作品显示「待核查」。

## 常见问题

- **提示登录态失效**：请先在浏览器正常打开 wawawriter.com 并登录，再回到扩展点击按钮。
- **没有读取到作品**：请确认当前账号在「投稿中心」创建过投稿。
- **收益列为 —**：该作品未签约或昨日数据尚未生成（previous.available = false），与官方页面展示逻辑一致。
